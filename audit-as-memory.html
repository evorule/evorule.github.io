审计即记忆

大多数 AI agent 有两个系统——记忆（为了有用）和日志（为了真实），两套存储、两种信任。evo-agent 只有一套：审计链是事实的唯一底座，记忆是从链上长出来的投影。记忆可以重建、可以审计、可以解释，唯独难以伪造。

链 = 唯一事实源 记忆 = 投影 · 可重建 变更即事件 身份以链为界

一次倒转

不是"审计顺便记录了记忆"，而是"记忆从审计中长出来"。

常规架构：两个系统

  • 记忆系统：为 agent 自己服务，优化"有用"——可合并、衰减、覆盖
  • 审计系统：为外部验证者服务，优化"真实"——只增不删
  • 信任模型："姑且相信记的是真的" vs 密码学可验证
  • 记忆可能被投毒、被捏造，与真实经历无法区分

    • evo-agent：折叠成一套

  • 审计链是唯一的事实底座
  • 记忆 = 链的投影、索引与派生视图——不是另一个事实存储
  • 每条记忆携带可回溯的因果出处
  • 每次记忆变更本身也是一个审计事件
    • 判定规则只有一条：一条记忆可信，当且仅当它能回溯到链上事实。无出处的记忆就是不可信的记忆——记忆投毒这一整类攻击不是靠检测封死的，是靠构造排除的。

    这意味着什么

    六层含义，每一层都对应仓中可核对的机制。

    含义 1

    单一事实源

    记忆降格为缓存：可删除、可重建、可丢弃重算——唯独不可伪造。

    含义 2

    漂移有账

    摘要被重写、偏好被覆盖、旧条目被合并——每次记忆变更都是链上事实。"agent 为什么变成这样"从解释变成可查的变更史。

    含义 3

    重放即重建

    空白实例 + 审计链 = 完整重演记忆状态。迁移=复制链；两个 agent 的差异=比对两条链。

    含义 4

    事实-解释-绑定

    事实在链上；解释（摘要/归纳）是锚定在链上的模型变换；先记账再压缩，压缩本身也落账。

    含义 5

    注意力可审计

    召回了什么、裁掉了什么、组装了什么，逐调用入账——"决定是在什么上下文里做出的"可验证。

    含义 6

    记忆主张可证明

    "我经历过 X，所以我知道 Y"——第三方可拿证据文档独立验证这个主张的链上出处。

    agent 的"自我"有了工程定义：那条链，加上在链上可重放的全部解释。
    —— 这不是修辞，是可执行的语义：重放链 + 重放变换 = 重演出这个 agent

    哪些已经是事实

    以下机制已在公开仓库中在役，可核对——我们不把"计划"写进这一节。

    ✓操作日志链化——逐行哈希三元组，自有链并锚定引擎链
    ✓记忆沉淀逐字在链——记忆/摘要/偏好作为事实入链（端到端实测）
    ✓记忆事件链锚——事件存储带链锚与防篡改对账
    ✓召回入账——每次检索的结果集落账，注意力可审计
    ✓上下文组装入账——发送全文+哈希、裁剪边界逐调用在账
    ✓压缩先记账——摘要/压缩全经审计协议，无影子调用
    ✓状态重建——会话恢复走日志重放（历史/待审批/计数器）
    ✓冷热分层带账面——分层回答成本，迁移落账不破坏可追溯

    尚未做到什么

    这些是当前真实边界——写明缺口，不做愿景冒充现状。

    出处锚尚未全覆盖

    记忆条目与链上事实的绑定目前是对账机制级，尚未做到每条派生记忆逐一携带完整出处——在途工作，不冒充已完成。

    跨会话长期记忆收敛中

    会话内的链化与重建纪律已闭合；跨会话、跨实例的长期记忆面正在收敛到同一纪律。

    遗忘与只增不删的张力

    "遗忘"的正确语义是丢弃派生视图而非事实；但事实含用户内容时，只增不删与删除权存在真实张力。当前立场：本地账本归用户可整体销毁，引擎链随会话处置；多租户与合规场景需部署级裁决——我们不假装它在架构层已一劳永逸。

    成本与分层的铁律

    全链记忆不免费——存储、召回时延、验证开销。冷热分层是对成本的回答，但分层不降信任：任何一层的条目都保留链上锚定，否则"审计即记忆"在冷层断掉。

    设计原则

    1. 事实只存一次——链是唯一事实源；一切记忆形态（索引、摘要、向量、缓存）都是投影，可删可重建。
    2. 先记账，再压缩——任何有损变换必须先有完整账，变换本身也是账；解释永远可回溯到事实。
    3. 变更即事件——记忆的写入/覆盖/合并/归档/迁移一律入链；漂移必须可解释。
    4. 分层不降信任——分层回答成本，锚定保住信任。
    5. 身份以链为界——链外的状态不构成身份。这是刻意收缩的承诺。
